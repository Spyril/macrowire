Licensing correspondence
========================

The record of licensing positions stated in the project README that rest
on correspondence rather than on a published document.

Where a position rests on public terms - a robots.txt, a website's terms
of use - the README quotes the document and anyone can go and read it.
Where it rests on a letter, there is nothing for a reader to go and read,
so what is recorded here is the request, the answer in summary, and the
counterparty's own reference.

Retention
---------

Verbatim correspondence is retained privately by the operator and is
available on request. It is deliberately not reproduced in this
repository.

The reason is the same one that produced the correspondence in the first
place. Consent was sought to ACCESS a site; permission to republish the
counterparty's own words was never asked for and never given. A project
whose whole position is that it asks first should not publish someone
else's letter on the strength of having received it.

What this means for a reader
----------------------------

A summary is this project's account of what a letter said, and an account
is worth less than the thing itself. That is a real cost and it is not
argued away here.

What replaces the letter is the counterparty's own reference number, which
is recorded in full. A reader who doubts a summary can put the reference
to the counterparty and get the answer from the party that issued it -
verification against the source rather than against this repository. A
pasted letter would offer less: it could only be read, and would still
have to be believed.

Rules for this directory
------------------------

1. SUMMARY, CLEARLY LABELLED AS ONE. These files record what was sent and
   what came back, in this project's words, never presented as a
   quotation. An unmarked paraphrase would look like evidence while being
   someone's account of evidence, which is worse than having nothing.

2. THE REFERENCE IS NOT OPTIONAL. It is the whole verification mechanism.
   A file recording an exchange with no reference to it records an
   assertion.

3. Redact contact details. Personal email addresses and phone numbers do
   not belong here even in a summary.

4. Filename: date, counterparty, direction, and the counterparty's own
   reference where one exists.
