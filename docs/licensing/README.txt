Licensing correspondence
========================

Primary sources for the licensing positions stated in the project README.

They are kept here so those positions can be VERIFIED rather than taken on
trust. A README that says an exchange refused consent is worth exactly as
much as the reader's willingness to believe it. The letter is not.

Rules for this directory
------------------------

1. VERBATIM ONLY. These files hold what was actually sent and actually
   received, copied without editing. A summary belongs in the README,
   where it is visibly a summary. A paraphrase in here would look like
   evidence while being someone's account of evidence, which is worse
   than having nothing.

2. Redact contact details, not substance. Personal email addresses and
   phone numbers can go; a sentence cannot.

3. Filename: date, counterparty, direction, and the counterparty's own
   reference where one exists.
